\section{관련 연구}
\label{sec:related}

방어 자산을 표적에 배분하는 문제는 무기-표적 할당(WTA)으로 정식화되어 왔으나~\citep{ahuja2007wta},
이전 결정이 이미 막은 회랑과 남은 자산에 따라 달라지는 판단은 고정된 거리·각도 비용으로
표현되지 않으므로 본 연구는 배정 계층에 조합 최적화 대신 언어모델의 판단을 둔다. 무인 위협의
무력화 수단 가운데 연성 대응은 유선 조종 표적에, 경성 대응은 요격 비용의 비대칭에 막혀
포획이 남는다~\citep{wang2021cuas, sutea2026fiber, rumbaugh2024cost}. 해상의 강화학습 협조
포위~\citep{zhang2025encircle}는 방어정이 표적보다 빠르거나 대등함을 전제하므로, 더 느린
조건에서는 추격 대신 접근 경로의 선제 차단이 남는다.

다중 에이전트 강화학습의 중앙 집중 학습·분산 실행 계열은 팀 보상에서 개체별 기여를 분리하려고
가치망을 학습한다~\citep{rashid2018qmix, foerster2018coma, yu2022mappo}. 그룹 상대 정책
최적화(GRPO)~\citep{shao2024deepseekmath}는 같은 상태에서 뽑은 여러 후보의 보상을 서로 비교해
가치망 자체를 없앤다. 본 연구는 GRPO를 다중 에이전트 제어로 옮기되, 후보 하나를 기하
휴리스틱으로 고정해 기준선으로 삼고 후보의 팀 보상을 시뮬레이터 재진행으로 얻으며, 같은 픽셀
행동공간 위의 MAPPO를 갱신 규칙의 비교 기준으로 둔다(\ref{sec:res_algo}절).

모든 픽셀에 값을 매기는 조밀 예측과 조건 변조~\citep{ronneberger2015unet, perez2018film}는 주로
상황 지각에, 후보마다 점수를 매겨 하나를 지목하는 출력~\citep{vinyals2015pointer,
vaswani2017attention}은 조합 최적화에 쓰였다. 본 연구는 점수맵을 정책의 행동 분포로 삼아 둘을
잇고, 안전 제약을 마스크로 행동 분포에 직접 부과한다(\ref{sec:policy}절). 언어모델을 계획
주체로 쓰는 연구는 지시를 실행 가능한 단계로 분해하고 실행 가능성으로 계획을
거르며~\citep{huang2022zeroshot, ahn2022saycan}, 구조적 출력~\citep{openai2026function}으로 파싱
가능한 형태를 보장한다. 본 연구는 언어모델에 배정만 맡기고 실행 가능성은 기동 계층의 유효
마스크가 픽셀 수준에서 강제한다(\ref{sec:validmask}절).
