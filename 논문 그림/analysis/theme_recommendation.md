# 테마/팔레트 추천

## 참조 방법에 대한 메모
이번 작업은 `theme-seminar` 스킬의 9종 무드 중 하나를 그대로 쓰는 일반 발표 슬라이드가 아니다.
요청 파라미터로 들어온 `theme=seminar / mood=technical-report`는 **작업 계열을 지정하는
메타데이터로만 채택**했고, 실제 배색·캔버스·텍스트 규칙은 `anlasis/figure_brief.md` §1의 전역
오버라이드가 그 무드의 기본값(4색 팔레트, 3840×2160 고정 16:9)을 전부 대체한다. 즉 technical-report
무드가 "공식적·구조 중심적"이라는 톤 방향은 유지하되, 색상 값 자체는 무드 사전이 아니라
브리프 §2의 학술지 전용 8색+viridis 표를 그대로 쓴다.

## 문서 특성 분석
- 톤앤매너: 대한조선학회논문집(SNAK) 투고 원고의 본문 도판. 서술체가 아니라 학술 관례를 따르는
  기술 도해체 — 해면 장면은 실사 항공/CAD 오버레이 관례, 모델 도해는 딥러닝 논문(U-Net 계열)
  표기 관례를 그대로 따른다.
- 핵심 키워드: ["물리적 포획", "접근 회랑 차단", "두 계층·비동기 사이클", "LLM 구조적 출력",
  "다채널 래스터 관측", "U-Net 점수맵 정책", "순차 픽셀 선택", "그룹 상대 정책 최적화",
  "반사실 기여 할당"]
- 시각화 목적: 설명(체계 구조·데이터 표현·모델 구조 이해) 중심. 발표 자료와 달리 설득·대비
  연출보다는 **학술지 심사·재현성 관점의 정확한 표기**(채널 수, 해상도, 연산 화살표 색 관례,
  이진 마스크, viridis 컬러바)가 우선한다.

## 추천 테마
- **선택 테마**: seminar (요청값 그대로 채택 — 다만 위 메모대로 배색 자체는 브리프가 대체)
- **선택 무드**: technical-report (요청값 그대로 채택)
- **선택 근거**: 학술지 논문 도판이라는 목적에는 9종 무드 중 "연구/기술 문서, 공식 보고서,
  학술 발표"에 대응하는 technical-report가 톤 방향으로는 가장 가깝다. 다만 이 무드의 기본
  4색 팔레트는 학술지가 요구하는 실사 사진 질감(Register A)·viridis 히트맵(Register B)을
  담을 수 없으므로, 색상 값은 아래 고정 팔레트로 전면 대체한다.

## 전 도판 공통 제약 (재확인)
- 이미지 안에 `Fig. 1` / `Figure 1` / 그림 번호 / 도판 제목을 넣지 않는다 — 캡션은 LaTeX
  `\caption{}`이 담당한다.
- 텍스트는 영어만, 명사구 1~3단어. 한글·한자·가나·키릴 문자 전면 금지.
- 배를 아이콘(속 빈 삼각형·쉐브론·픽토그램·플랫 실루엣)으로 대체하지 않는다 — Register A는
  반드시 사진 수준 탑다운 3D 렌더.
- Register B는 U-Net 계열 논문 관례의 필수 표기(오블리크 텐서 슬래브, 박스 위 채널 수, 레벨 옆
  90도 회전 해상도, 색 구분 연산 화살표, 회색 점선 skip, 실제 렌더된 viridis 히트맵, 세로
  컬러바, 대괄호 갖춘 진짜 행렬)를 생략하지 않는다.
- 네거티브 스페이스 15~25%. 45도 아이소메트릭 3D, 매거진 에디토리얼 레이아웃, 대형 헤드라인,
  번호 배지, 네온/글로우 금지(브리프 §6 전체).
