# 도판 구성 계획

## 전체 구조
- 총 도판 수: **6매** (`figure_brief.md` §4 Fig.1~Fig.6 그대로. 늘리거나 줄이지 않는다)
- 산출물 성격: 학술지(SNAK) 투고 원고 본문 도판. 발표 슬라이드 세트가 아니므로 "표지"·"클로징
  요약" 슬라이드가 없고, 6매 모두 논문 본문 서술 순서를 그대로 따라 배치된다.
- 스토리라인(=논문 §1~§2.3 서술 순서와 1:1 대응):
  1. 문제 설정과 그물 포획 전제 (Fig.1)
  2. 두 계층·비동기 사이클이라는 체계 전체 구조 (Fig.2)
  3. 상위 계층: LLM 지휘관의 배정이 하위 계층의 선행 조건임 (Fig.3)
  4. 하위 계층 입력: 다채널 래스터 관측 (Fig.4)
  5. 하위 계층 정책: U-Net 점수맵과 순차 픽셀 선택 (Fig.5, 핵심 도판)
  6. 학습 방식: 그룹 상대 비교 + 반사실 기여 할당 (Fig.6)
- 범위: 정량 성능 수치(포획률, 정확도, 손실값, 보상값, 지연 ms)는 어떤 도판에도 넣지 않는다
  — 측정되지 않은 값을 창작하지 않는다는 사실성 원칙(브리프 §5, `.tex` 헤더 동일). 도판에 넣는
  숫자는 오직 체크포인트 config·모델 구조에서 실측 확인된 것(15, 50×50, 32, 64, 25×25, 13×13,
  채널 묶음 9/3/3)뿐이다.
- 미해결 항목: 그물벽 최대 길이(본문 150 m 대 체크포인트 450 m)가 미확정이라 Fig.1·Fig.5의
  그물벽 길이는 정확한 실측 비례가 아닌 상호 일관적 스키매틱 비율로 둔다(`concepts.md` 참조).

## 레지스터 배치 점검
- 6매 중 A 전면 1매(Fig.1), B 주도+A 삽입 2매(Fig.2, Fig.5), 상하/좌우 분할형 2매(Fig.3, Fig.4),
  A+B 병렬형 1매(Fig.6)로 두 레지스터가 매번 다른 조합으로 등장해 6매 전체가 시각적으로
  단조롭지 않다.
- 양단(12:5, 전폭) 도판은 Fig.2·Fig.5 두 곳뿐이며 둘 다 B 레지스터가 주도하는 도판이다 — 좌→우
  파이프라인을 그릴 만큼 가로 공간이 필요한 도판에만 전폭을 배정했다는 점에서 캔버스 선택과
  내용 구조가 일치한다.
- 단단(4:3) 도판 4매(Fig.1, 3, 4, 6) 중 Fig.1만 A 전면이고 나머지 3매는 모두 A/B 혼합이다 —
  단단 도판이라고 반드시 단순 실사 장면인 것은 아니며, 오히려 좁은 폭 안에 두 레지스터를
  압축해야 하는 도판이 더 많다.
- **모든 도판이 §2의 동일한 8색+viridis 팔레트를 공유**한다. 도판별로 팔레트를 바꾸지 않는다
  (`theme_recommendation.md` 참조).

## 텍스트 예산 점검
- render_text는 전부 브리프 §4 원문을 그대로 사용했으며 임의로 추가·번역·변경한 라벨은 없다.
  도판별 텍스트 항목 수: Fig.1 10개 / Fig.2 15개 / Fig.3 18개 / Fig.4 18개(수치 포함) /
  Fig.5 26개(수치 포함, 핵심 도판이라 채널·해상도 표기가 가장 많음) / Fig.6 12개.
- Fig.4·Fig.5의 수치 라벨(15, 50×50, 32, 64, 25×25, 13×13, 9/3/3)은 이 장르(U-Net 논문 도해)의
  표기 관례이지 설명문이 아니므로 텍스트 과다로 취급하지 않는다(브리프 §3 Register B, §5).
- Fig.6은 의도적으로 축 눈금 숫자를 넣지 않는다 — 측정되지 않은 정량값을 창작하지 않기 위함.
