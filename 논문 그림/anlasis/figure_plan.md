# 도판 선정 근거 — 왜 이 6장인가

## 후보 11개에서 6개로

코드와 초안에서 도판이 될 수 있는 것을 전부 뽑으면 11개였다.

(a) 교전 개념·그물 포획 · (b) 2계층 구조 · (c) 비동기 타이밍 · (d) 지휘관 구조적 출력 ·
(e) 유효 마스크 기하 · (f) 다채널 래스터 · (g) U-Net 구조 · (h) 질의·내적 점수맵과 순차 선택 ·
(i) 픽셀 → 경유점 → 그물벽 디코딩 · (j) GRPO 그룹상대 + 반사실 기여 · (k) 보상 구성

기준은 하나다 — **이 그림이 없으면 독자가 본문을 따라갈 수 없는가.**

`figure*` 는 선언된 페이지에 놓이지 못하고 **다음 페이지 단 상단**으로 넘어간다.
그래서 Fig. 2 는 서론 끝에서 선언해야 2쪽 상단에 온다. 아래로 옮기면 3쪽으로 밀린다.
번호는 `\begin{figure}` **선언 순서**로 매겨지므로 순서를 바꾸면 Fig. 번호가 어긋난다.

검증: xelatex 2회 통과, 5쪽, undefined reference 0, Fig. 1~6 순서대로 매겨짐.

# 스타일 방향 — 1차 시도가 실패한 이유

첫 프롬프트 묶음은 `발표_서론편` 의 프롬프트 **구조**는 가져오면서 시각 어휘를
"플랫 2D 라인 아트, 외곽선만, 컬러맵 금지, 컬러바 금지, 텐서 shape 표기 금지"로 잡았다.
AI 티를 빼려다 **클립아트**가 됐다. 구체적 실패는 셋이다.

1. **배를 속 빈 삼각형·쉐브론으로 그렸다.** 실제 USV 논문의 개념도는 위성/항공 영상 위에
   실사 선박을 얹고 그 위에 CAD 주석을 오버레이한다. 아이콘으로 대체하면 발표 슬라이드지 논문이 아니다.
2. **모델 도판에서 이 장르의 필수 표기를 전부 금지했다.** 채널 수, 공간 해상도, 오블리크
   텐서 슬래브, 색으로 구분된 연산 화살표, 회색 점선 skip, 컬러바 — 이게 U-Net 계열 도해를
   "논문 그림"으로 읽히게 하는 관례다. 텍스트 예산을 아끼려다 장르 표지를 지웠다.
3. **행렬을 행렬로 그리지 않았다.** 래스터가 결국 수치 행렬이라는 사실을 보이려면 대괄호와
   셀 값을 가진 진짜 행렬 콜아웃이 필요하다.

## 수정 방향 — 두 레지스터

`style_sheet.md` §0 에 못박았다.

- **Register A (해면 장면)**: 위성 정사영상 품질 실사 + 사진 수준 탑다운 선박 렌더 +
  반투명 CAD 오버레이. 그물은 주황 부표열 + 수면 아래 망의 실물.
- **Register B (모델·데이터)**: 딥러닝 논문 관례 그대로. 오블리크 텐서 슬래브, 박스 위
  채널 수, 레벨 옆 90도 회전 해상도, 파랑/빨강/초록 연산 화살표, 회색 점선 skip,
  실제 렌더된 viridis 히트맵, 세로 컬러바, 대괄호를 갖춘 진짜 행렬·열벡터.

한 장 안에 둘이 섞일 수 있고(Fig. 3·4·5·6), 그때 각 부분은 자기 관례를 지킨다.

"AI 티 차단"은 이제 **네온·글로우·어두운 SF 대시보드·뇌/회로기판 모티프·45도 마케팅
아이소메트릭** 을 막는 쪽으로만 작동하고, 학술 관례 자체는 건드리지 않는다.

## 텍스트 정책

- 이미지 안 텍스트는 **영어만**. 한글 단 한 글자도 금지.
- 라벨은 명사구 1~3단어. 문장 금지.
- **채널 수·해상도 같은 수치 주기는 텍스트 예산에서 제외**한다. 이건 설명문이 아니라
  이 장르의 표기 규약이고, 빼면 오히려 도판이 헐거워진다.
- 이미지 안에 `Fig. 1` / 도판 제목을 넣지 않는다 — 캡션은 LaTeX 가 단다.

## 수치의 출처

도판에 들어가는 `15`, `50 x 50`, `32`, `64`, `25 x 25`, `13 x 13`, 채널 묶음 `9 / 3 / 3` 은
전부 체크포인트 `boatattack_sim/models/u-net_map.pt` 의 config 와
`model/cnn_actor.py::UNetLite` 구조에서 확인한 실제 값이다 (`docs/unet_model_deploy.md` §1, §3).

반대로 **측정되지 않은 값은 도판에 넣지 않는다.** Fig. 6 의 막대 차트에 축 눈금 숫자를
뺀 것이 그 적용이다. 초안 헤더의 사실성 원칙과 같은 기준이다.
