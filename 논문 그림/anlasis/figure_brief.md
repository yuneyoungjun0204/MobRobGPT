## 3. 두 레지스터 — 도판마다 어느 쪽인지 지정돼 있다

### Register A — 해면 장면
- **선박은 사진 수준 탑다운 3D 렌더**다. 갑판 구조물·함교·마스트·항적 거품·선체 그림자가 보인다.
- 속 빈 삼각형, 쉐브론, 아이콘, 픽토그램, 플랫 실루엣으로 배를 대체하면 **실패**다.
- 해면은 단색 면이 아니라 실제 수면 — 미세 파문, 스웰, 깊이에 따른 색 변화.
- 시점은 거의 수직 탑다운. 수평선·하늘이 보이면 안 된다.
- 조명은 좌상단 고각 단일 태양. 모든 그림자 방향이 일치한다.
- 그물은 아이콘이 아니라 **실물** — 등간격 주황 부표 줄 + 수면 아래 비치는 검은 망.
- 그 위에 **반투명 CAD 오버레이**: 거리환, 코리도 부채꼴, 항적선, 치수선, 지시선.
  불투명도 25% 이하로 아래 사진 질감을 덮지 않는다.

### Register B — 모델/데이터
- 딥러닝 논문 도해 관례를 그대로 따른다.
- 텐서는 **오블리크 슬래브 박스** (정면 사각형 + 얇은 상단/측면 사면). 납작한 사각형 금지.
- **박스 위에 채널 수 숫자**, **레벨 옆에 90도 회전한 공간 해상도** 를 적는다.
  이건 텍스트 과다가 아니라 이 장르의 필수 표기다. 빼면 도판이 헐거워진다.
- 특징맵·점수맵은 **실제 렌더된 viridis 히트맵**. 회색 격자에 손칠한 색 금지.
- 마스크는 **진짜 이진 행렬** (검정 바탕 + 순백 셀 + 셀 격자 + 양옆 대괄호).
- 행렬·열벡터는 **키 큰 대괄호**를 갖춘 진짜 행렬로 그린다.
- 화살표 색 관례: 파랑=합성곱, 빨강=다운샘플, 초록=업샘플, **회색 점선=skip connection**, 검정=일반 흐름.
- 히트맵 옆에 **세로 컬러바** + 양 끝 눈금을 넣는다.

한 도판 안에 A·B가 섞일 수 있고, 그때 각 부분은 자기 관례를 지킨다.

### Fig. 6 — Group-relative training with counterfactual credit  `fig6_grpo.png`
- 레지스터: **A (롤아웃 실사 패널) + B (차트/행렬)**
- 캔버스: 2400×1800 (4:3), 단단 80 mm
- Key message: 후보 행동들을 실제로 진행시켜 서로 비교하고, 한 척만 바꾼 차이를 그 배의 기여로 돌린다.
- scene_context: 상단 — 결정 시점 점수맵 타일 하나에서 화살표가 부채꼴로 갈라져 후보 타일 4개로

  중간 — **실사 항공 롤아웃 패널 4개가 가로로**. 네 패널은 **같은 해역·같은 초기 배치**이고
  그물 위치와 흰 파선 항적만 다르다. 두 패널에선 적이 그물 뒤에서 정지, 다른 패널에선 적이 통과.
  아래 공통 시간 브래킷. 각 패널 아래 막대 하나씩 올라와 **막대 차트**를 이룬다.
  하단 — 좌측은 **0선 기준 이득 막대 차트**(위 2개 아래 2개, 회색 파선이 그룹 평균).
  우측은 **대괄호를 가진 3행×4열 행렬**, 셀마다 아군 마커. **둘째 행만** 파란색이고 셀마다 방향이
  다르며(섭동), 나머지 행은 회색이고 행 안에서 방향이 모두 같다(고정). 둘째 행에 틴트 띠와 브래킷.
- **축 눈금 숫자를 넣지 않는다** — 측정되지 않은 값을 창작하지 않기 위한 의도적 선택.
- render_text: Decision state / Candidate actions / Heuristic seed / Rollout window / Team reward /
  Group-relative advantage / group mean / Counterfactual / perturbed / fixed / candidates / vessels

## 5. 수치 표기의 출처 (창작 아님)

`15`, `50 x 50`, `32`, `64`, `25 x 25`, `13 x 13`, 채널 묶음 `9 / 3 / 3` 은 전부 체크포인트
`boatattack_sim/models/u-net_map.pt` 의 실제 config 와 `model/cnn_actor.py::UNetLite` 구조에서

**반대로 측정되지 않은 값(포획률, 정확도, 손실값, 보상값, 지연 ms)은 도판에 숫자로 넣지 않는다.**
