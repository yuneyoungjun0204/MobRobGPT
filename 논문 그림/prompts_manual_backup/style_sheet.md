# Style Sheet — Journal Figure Set (SNAK, 2-column A4)

목표는 *Ocean Engineering* / *IEEE JOE* / *MICCAI* 계열 논문에서 그대로 뽑아낸 것처럼 보이는 도판이다.
플랫 아이콘 도해가 아니다. 6장 전체에 걸쳐 이 시트는 **고정**된다.

---

## 0. 두 개의 레지스터 — 도판마다 어느 쪽인지 먼저 정한다

논문 도판은 성격이 다른 두 종류가 섞여 있고, **각각의 관례가 완전히 다르다.**
한 장 안에 둘이 같이 나올 수 있으며(예: Fig. 5 우측 해면도), 그때는 각 부분이 자기 관례를 지킨다.

### Register A — 해면 장면 (Operational scene)
실제 해역을 위에서 내려다본 장면. **선박은 실사 수준으로 렌더링한다.**

- 선체는 **사진 수준의 탑다운 3D 렌더 또는 고밀도 테크니컬 일러스트레이션**이다.
  갑판 구조물, 함교, 선수 파도, 항적 거품, 선체 음영이 보인다.
- 아이콘·픽토그램·속 빈 삼각형·쉐브론으로 배를 대체하면 **실패**다.
- 해면은 단색이 아니라 실제 수면 — 미세한 파문과 깊이에 따른 색 변화가 있다.
  해도(nautical chart) 풍의 등심선·연안 음영을 배경으로 깔아도 좋다.
- 육지는 실제 해안선 형상 + 옅은 지형 음영.
- 그 위에 **벡터 주석 오버레이**를 얹는다: 거리환, 코리도 부채꼴, 항적선, 치수선, 지시선, 라벨.
  주석은 반투명 도형 + 얇은 실선으로, 사진 위에 CAD 를 얹은 느낌이어야 한다.
- 즉 **실사 베이스 + 벡터 오버레이**의 2층 구조다. 이게 방위·해양 논문의 개념도 관례다.

### Register B — 모델/파이프라인 (Network & data-flow)
텐서와 연산을 그리는 부분. **딥러닝 논문의 표준 관례를 그대로 따른다.**

- 텐서는 **입체감 있는 슬래브 박스**로 그린다 — 정면 사각형 + 상단/측면 사면(oblique).
  U-Net·AlexNet·VGG 논문 도해의 그 박스다. 납작한 사각형만 쓰면 실패다.
- 각 슬래브에는 **채널 수를 박스 위에**, **공간 해상도를 박스 옆에** 숫자로 적는다.
  (`64`, `128`, `50×50`, `25×25` …) 이건 텍스트 과다가 아니라 이 장르의 필수 표기다.
- 특징맵·점수맵·마스크는 **실제로 렌더링된 이미지 썸네일**로 보여준다.
  회색 격자에 색칠한 시늉이 아니라, 진짜 히트맵/바이너리 마스크가 그려져 있어야 한다.
- **매트릭스는 매트릭스로 그린다.** 셀 경계가 보이는 격자, 필요하면 셀 안에 값,
  가장자리에 인덱스, 행렬 양옆에 대괄호. 논문에서 행렬을 그리는 바로 그 방식.
- 연산은 화살표 종류로 구분한다(관례 그대로):
  파란 실선 = conv 블록 / 빨간 아래 화살표 = downsample / 초록 위 화살표 = upsample /
  **회색 점선 수평 화살표 = skip connection** / 검정 실선 = 일반 데이터 흐름.
- **컬러바를 넣는다.** 히트맵을 그렸으면 옆에 세로 컬러바와 양 끝 눈금이 붙는다. 이게 정상이다.
- 컬러맵은 **viridis 하나로 고정**한다. 무지개(jet) 금지, 다중 컬러맵 혼용 금지.

## 1. 색 (locked)

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| ink | `#1F2933` | 주선, 박스 외곽, 라벨 텍스트, 치수선 |
| gray | `#7B8794` | 보조선, 격자, skip 화살표, 지시선 |
| sea | `#8FA8BC` → `#5B7C95` | 수면 (얕은→깊은 자연스러운 변화) |
| land | `#E3DCC9` | 육지 면, 해안선은 `#B5AC93` |
| blue | `#1F5FA8` | 아군·모선·그물·유효영역 오버레이 |
| red | `#C0392B` | 적 표적·위협·돌파 오버레이 |
| tensor | `#EAF2F8` 면 + `#2C3E50` 외곽 | Register B 슬래브 박스 |
| colormap | **viridis** | 특징맵·점수맵 히트맵 전용 |
| white | `#FFFFFF` | 도판 배경(Register B), 여백 |

흑백 인쇄 안전성: 적/아군은 색뿐 아니라 **마커 형태**로도 갈린다
(적 = 빨간 원형 표적링, 아군 = 파란 각진 마커). 유효/무효 영역은 틴트뿐 아니라 **해칭**으로도 갈린다.

## 2. 선·화살표

- 굵기 2단계: 주선 2 px, 보조선 1 px. Register B 의 텐서 박스 외곽은 1.5 px.
- 화살촉은 **채워진 삼각형**으로 통일(속 빈 화살촉은 얇은 인쇄에서 뭉개진다).
- skip connection 만 예외로 회색 점선 + 얇은 화살촉.
- 주 데이터 흐름은 좌→우. 역방향은 명시적으로 의미가 있는 경우에만.

## 3. 타이포그래피

- 산세리프 단일 패밀리(Helvetica / Arial / Source Sans 계열). **영어와 숫자만.**
- 크기 3단계: 구역명(대) / 요소 라벨(중) / 수치·단위·채널수(소).
- 굵기 2단계: Regular, Medium. Bold 는 구역명에만.
- 라벨은 명사구 1~3단어. **문장 금지.** 수치 표기는 텍스트 예산에 포함하지 않는다.
- 이미지 안에 `Fig. 1` / `Figure 1` / 도판 제목을 **절대** 넣지 않는다 — 캡션은 LaTeX 가 단다.

## 4. 캔버스

| 용도 | 해상도 | 비율 | 인쇄 폭 |
|---|---|---|---|
| 단단 도판 `figure` | 2400 × 1800 | 4:3 | 80 mm |
| 양단 도판 `figure*` | 4200 × 1750 | 12:5 | 165 mm |

- 300 dpi 이상 상당. 가장자리 3 % 마진.
- 네거티브 스페이스 **15~25 %**. 학술 도판은 정보 밀도가 높아야 하지만 숨 쉴 곳은 있어야 한다.

## 5. 전 도판 공통 금지 (AI 티 차단)

- 네온, 글로우, 렌즈 플레어, 홀로그램, 파티클, 빛나는 청색 HUD
- 어두운 SF 대시보드 배경, 사이버펑크 색조
- 뇌 모양, 뉴런 노드-엣지 그물망, 회로기판, 로봇 얼굴 — AI 상투 모티프 일체
- 45도 아이소메트릭 "3D 오브젝트가 흰 배경에 떠 있는" 마케팅 일러스트 스타일
- 드롭섀도, 베벨, 유리 반사, 과장된 앰비언트 오클루전
- 이미지 안 캡션·도판 제목·워터마크·로고
- 한글·한자·가나·키릴 문자
- CONTENT 블록에 없는 임의 생성 문장
- 원문에 없는 정량 성능 수치(포획률, 정확도, 손실값)
