# 슬라이드 구성 계획

## 전체 구조
- 총 슬라이드 수: 16장
- 스토리라인: 자동화의 빈 층(문제) → 왜 어려운가(난점) → 왜 규칙도 모방도 단독으론 안 되는가(대비①) → 무엇을 묻는가(질문) → 무엇으로 채우는가(데이터·관측·정규화·라벨) → 어떻게 학습하는가(BC→GRPO, 대비②) → 어떻게 채점·억제하는가(보상) → 무엇으로 구현했는가(백본·인코더) → 무엇을 명령하는가(대비③) → 어떻게 검증하는가(평가철학) → 그래서 무엇이 남는가(의의·과제)
- 범위: 서론·문제의식·동기·연구 의의·접근 방식만 포함. 정량 성능 수치는 포함하지 않음(문서 범위 밖, 결과편 별도)
- 핵심 대비축 3개 배치: ①규칙기반 대 학습(슬라이드4) ②열린 고리 대 닫힌 고리(슬라이드11) ③경유점 대 곡률(슬라이드14)
