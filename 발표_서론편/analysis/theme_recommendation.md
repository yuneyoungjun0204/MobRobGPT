# 테마/레이아웃 추천

## 참조 방법에 대한 메모
레이아웃 배정은 24종 레이아웃 정의를 근거로 작성했다.
색상 팔레트는 최초 산출 시 추론값(#1B2A41 / #3D5A73 / #D97706 / #F4F6F8)이 들어갔으나,
**`theme-seminar` 스킬의 technical-report 무드 정식 팔레트로 교정 완료**(2026-08-10). 아래 값이 확정본이다.

## 문서 특성 분석
- 톤앤매너: 공식적이면서 기술적. 다만 청중 절반 이상이 AI 비전공자이므로 서술은 학술 논문체가 아니라 "문제 → 자체 실험 → 결론"의 내러티브 톤
- 핵심 키워드: ["자동화의 빈 층", "규칙 기반 대 학습", "분포 이탈", "열린 고리 대 닫힌 고리", "그룹 상대 정책 최적화", "곡률 대 경유점", "오프라인 강화학습"]
- 시각화 목적: 설명(구조·개념 이해) + 설득(왜 이 접근이 필요한가) + 대비(경쟁하는 두 방법론의 우열)

## 추천 테마
- **선택 테마**: seminar (요청값 그대로 채택)
- **선택 무드**: technical-report (요청값 그대로 채택)
- **선택 근거**: 연구소 인원(기술 전문가)과 조선소 실무진(비전공자)이 혼재한 사내 세미나이며, 자체 실험 결과와 설계 근거를 순서대로 제시하는 기술 보고서 성격의 발표다. 9종 무드 중 "연구/기술 문서, 공식 보고서, 학술 발표"에 가장 부합하는 technical-report가 적합하며, 화려한 장식보다 구조도·수치 라벨의 가독성을 우선하는 무드 특성이 본 발표의 목적(합의 형성, 설계 결정 설명)과 일치

## 고정 팔레트
primary: #2C3E50 (네이비 — 제목·헤더·핵심 구조선, 신뢰감과 격식 부여)
secondary: #5D6D7E (슬레이트 블루 — 본문 라벨·보조 도형·연결선)
accent: #2980B9 (딥 블루 — 핵심 수치·대비 강조 요소: "충돌 0%", "3.33배 증폭", "800m" 등 주목 포인트)
background: #F8F9FA (오프 화이트 — 슬라이드 배경, 장시간 시청 시 눈부심 최소화)

세션 전체 16개 슬라이드에 이 4색만 사용하며, 슬라이드별로 팔레트를 바꾸지 않는다.

## 슬라이드별 레이아웃 배정

| 슬라이드 | 레이아웃 | 선택 근거 |
|:--------:|----------|-----------|
| 1 | Z-Pattern | 오프닝 훅. 좌상단 문제제기→우하단 결론 유도로 발표 방향을 한 장에 각인 |
| 2 | Structure | 상위(항로계획)-중간(공백)-하위(조타) 3단 레이어 구조를 그대로 시각화 |
| 3 | Card-Grid | 정답다중성·안전암묵성·가변입력, 병렬적인 3개 난점을 동등 카드로 나열 |
| 4 | Contrast | 핵심대비①. 규칙기반(과잉반응) 대 순수모방(회피 미학습)을 좌우 병치 후 결합 결론 |
| 5 | Mind Map | 하나의 연구 주제에서 세 질문이 뻗어나가는 구조, 발표 로드맵 겸용 |
| 6 | Stacked Progress | 희소한 실데이터 위에 합성데이터(10/50/100척)가 단계적으로 누적되는 구성 표현 |
| 7 | Concentric | "근거리에 해상도를 배분"하는 소프트사인 설계 의도가 거리별 감도 링과 대응 |
| 8 | Flow | 원본 항적→300초 오프셋 추출→경유점/곡률 산출의 순차 처리 과정 |
| 9 | Contrast | 학습 시 상태분포 대 배포 시 상태분포, 근본적으로 다른 두 조건을 좌우 병치 |
| 10 | Cycle | 후보생성→채점→상대순위→확률상향, 4단계가 반복되는 최적화 루프 |
| 11 | Contrast | 핵심대비②. 열린 고리(단일스텝) 대 닫힌 고리(250스텝 롤아웃) 병치가 가장 선명 |
| 12 | Bento Grid | 보상 5요소 + 보수성 3장치, 서로 다른 성격의 모듈을 한 장에 압축 요약 |
| 13 | Section-Flow | 백본 비교 개요 + 주변선박 인코더 처리 흐름, 개요+흐름 결합에 적합 |
| 14 | Contrast | 핵심대비③. 경유점(왜곡) 대 곡률(무손실)을 좌우 병치해 설계 전환 근거 전달 |
| 15 | Group | 안전·모방·효율·규칙준수 4축과 비교군 8종이라는 분류 체계를 카탈로그로 배열 |
| 16 | Z-Pattern | 클로징 요약. 슬라이드1과 수미상관을 이루며 의의(좌상단)-과제(우하단) 정리 |
