# 핵심 개념 분석

## 문서 요약
- 문서 유형: 사내/연구 세미나 발표 자료 원고 (서론·문제의식·동기·연구 의의·접근법 편). 정량 결과는 문서 범위 밖이며 이번 슬라이드 세트에도 포함하지 않는다.
- 핵심 주제: 항로계획과 저수준 오토파일럿 사이에 남은 "중간층 조선 판단"을, 항해사 항적 기반 행동복제(BC)와 그룹 상대 정책 최적화(GRPO)로 학습해 메우는 접근
- 대상 청중: 조선소 실무진 및 연구소 인원. 참석자 절반 이상이 AI 비전공자 — 수식/전문용어는 최소화하고 구조도·비유 중심으로 전달

## 참고 사항 (레이아웃/테마 참조 방법)
`layout-types`, `theme-seminar` 스킬 파일은 컨텍스트에 자동 로드되어야 하는 리소스이나, 이번 세션에서는 로컬에 설치된 해당 플러그인 경로가 `honeypot` 마켓플레이스 하위(`...plugins\cache\honeypot\visual-generator\...`)로만 존재해 MUST NOT DO 항목("해당 경로를 변수로 사용하지 않음")과 "Read 불필요" 원칙에 따라 직접 Read하지 않았다. 대신 에이전트 정의에 이미 명시된 9종 무드 표·24종 레이아웃 표(요약본)를 근거로 매칭했다. 정식 스킬 컨텍스트가 별도로 주입될 경우 아래 배정을 그 내용과 대조 검증할 것을 권장한다.

## 슬라이드별 개념

### 슬라이드 1: 표지 — 자동화의 빈 층
- **핵심 메시지**: 항로계획과 저수준 조타는 이미 자동화됐지만, 그 사이의 판단은 여전히 항해사 숙련에 의존한다
- **주요 개념**: ["장기 항로계획 자동화", "오토파일럿 자동화", "중간층 판단 공백", "자율운항 병목"]
- **콘텐츠 분류**: render_text(제목/부제) + scene_context(브릿지·항로 구조 실루엣 배경)
- **권장 레이아웃**: Z-Pattern
- **레이아웃 근거**: 발표 오프닝 훅. 좌상단 문제제기에서 우하단 결론(자동화 병목)으로 시선을 유도해 한 장으로 발표 전체 방향을 각인

### 슬라이드 2: 문제 정의 — 자동화의 빈 층
- **핵심 메시지**: 장기 항로계획과 저수준 조타는 자동화됐으나, "지금 얼마나 돌릴 것인가"를 결정하는 중간층은 미해결이다
- **주요 개념**: ["장기 항로계획(경유점 열 확정)", "저수준 조타(오토파일럿, 지령 침로 유지)", "중간층: 조선 판단", "항해사 숙련 의존"]
- **콘텐츠 분류**: render_text(3단 레이어 레이블) + scene_context(상단 자동화·중간 공백·하단 자동화 층 구조 시각화)
- **권장 레이아웃**: Structure
- **레이아웃 근거**: 상위-중간-하위 3단 레이어 구성이며 중간 레이어가 비어있음을 강조해야 하므로 레이어 구조 레이아웃이 가장 직접적으로 대응

### 슬라이드 3: 세 가지 기술적 난점
- **핵심 메시지**: 중간층 자동화가 어려운 이유는 정답 다중성, 안전의 암묵성, 가변 입력 세 가지다
- **주요 개념**: ["정답 다중성(다중모드 문제)", "안전의 암묵성(회피 성공은 라벨이 없음)", "가변 입력(타선 수 변동)", "고정 크기 신경망의 한계"]
- **콘텐츠 분류**: render_text(카드별 난점명 + 한 줄 설명)
- **권장 레이아웃**: Card-Grid
- **레이아웃 근거**: 병렬적이고 대등한 3개 난점을 동일 비중 카드로 나열해 비교하기 적합

### 슬라이드 4: 대비① 규칙 기반 대 순수 모방 — 결합의 필요성
- **핵심 메시지**: 규칙 단독은 실교통에 과잉반응하고, 순수 모방은 위험 조우가 희박해 회피를 배우지 못한다 — 그래서 결합이 필요하다
- **주요 개념**: ["자체 제작 규칙기반 FSM(조우 5분류)", "교과서적 1:1 시나리오 9개: 충돌 0%", "실제 항해 로그: 과잉반응", "순수 모방: 회피 행동 미학습(위험 조우 희박)", "규칙에서 안전기준, 사람에게서 조선방식"]
- **콘텐츠 분류**: render_text(수치·결론 라벨: "충돌 0%" / "과잉반응") + scene_context(규칙 컨트롤러 대 모방 학습 두 경로가 대비되다 결합점으로 수렴하는 구도)
- **권장 레이아웃**: Contrast
- **레이아웃 근거**: 규칙기반 대 학습이라는 이번 발표의 핵심 대비축 중 하나. 좌우 병치 후 중앙 결합 결론으로 이어지는 Contrast 구조가 논리 흐름과 정확히 일치

### 슬라이드 5: 연구 질문
- **핵심 메시지**: 베테랑 항해사의 판단을 데이터에서 학습하고, 그 위에 안전기준을 덧씌우고, 실선 없이 기록 데이터만으로 강화학습이 가능한가
- **주요 개념**: ["항해사 판단의 데이터 기반 학습 가능성", "학습된 정책에 안전기준 추가 가능성", "실선 없는(오프라인) 강화학습 가능성"]
- **콘텐츠 분류**: render_text(질문 3개 문구)
- **권장 레이아웃**: Mind Map
- **레이아웃 근거**: 하나의 연구 주제에서 세 질문이 뻗어나가는 구조로, 발표 전체 로드맵 역할을 겸함

### 슬라이드 6: 데이터 — 희소한 실항적과 합성 보완
- **핵심 메시지**: 실항해 데이터는 귀하지만 조우가 희소해 합성 다중조우 시나리오로 규모를 보완한다
- **주요 개념**: ["실항적 54개 시퀀스", "시나리오당 타선 최대 2척(조우 희소)", "합성 시나리오: 타선 10/50/100척", "합성 규칙: 타선 상호충돌 배제 + 자선 조우 부여"]
- **콘텐츠 분류**: render_text(수치 라벨: 54개, 10/50/100척) + scene_context(실데이터 위에 합성 데이터가 층층이 쌓이는 이미지)
- **권장 레이아웃**: Stacked Progress
- **레이아웃 근거**: 희소한 실데이터 위에 합성 데이터가 단계적으로 누적되는 구성비를 표현하는 데 적합

### 슬라이드 7: 관측·정규화 — 단출한 입력과 소프트사인
- **핵심 메시지**: 자선 4채널·타선 2채널의 단출한 입력을, 표준화 대신 소프트사인 함수로 근거리에 해상도를 몰아 표현한다
- **주요 개념**: ["자선: 선수각 sin/cos + 목표 상대변위 2값", "타선: 상대변위 2값, 최대 10척(반경 10km)", "절대위치·속도 미포함", "소프트사인: 타선기준 600m/목표기준 10km에서 0.5"]
- **콘텐츠 분류**: render_text(채널 레이블, 기준값 수치) + scene_context(자선을 중심으로 근거리는 촘촘하고 원거리는 완만해지는 감도 링)
- **권장 레이아웃**: Concentric
- **레이아웃 근거**: "근거리에 해상도를 배분한다"는 핵심 설계 의도가 거리별 민감도가 감쇠하는 동심원 구조와 정확히 대응

### 슬라이드 8: 라벨 — 항적 자체가 정답
- **핵심 메시지**: 별도 주석 작업 없이 항적 자체에서 경유점과 곡률 라벨이 자동으로 산출된다
- **주요 개념**: ["정답 경유점: 300초 뒤 실제 위치(약 1.5km 이상 전방)", "정답 곡률: 300초간 선수각 변화량 ÷ 직선거리", "부호 규약: +우선회 / -좌선회", "사람 라벨링 불필요"]
- **콘텐츠 분류**: render_text(부호 규약, 시간창 수치) + scene_context(원본 항적 궤적에서 미래 시점 위치와 곡률이 추출되는 처리 흐름)
- **권장 레이아웃**: Flow
- **레이아웃 근거**: 원본 항적 → 300초 오프셋 추출 → 경유점/곡률 산출로 이어지는 순차적 데이터 처리 과정을 표현하기에 적합

### 슬라이드 9: 1단계 학습 — 행동 복제와 분포 이탈
- **핵심 메시지**: 행동복제는 데이터 효율이 높지만, 학습 시 조건과 배포 시 조건이 달라 오차가 누적되는 분포 이탈에 취약하다
- **주요 개념**: ["지도학습 기반 행동복제(BC)", "학습: 사람이 만든 올바른 상태에서 한 수", "배포: 자기가 만든 상태에서 연속 판단", "분포 이탈 누적", "비유: 필기시험만 만점인 초보 운전자"]
- **콘텐츠 분류**: render_text(핵심 한계 라벨: "분포 이탈") + scene_context(학습 궤적 대 배포 궤적이 갈라지는 도로 이탈 비유 장면)
- **권장 레이아웃**: Contrast
- **레이아웃 근거**: 학습 시 상태분포와 배포 시 상태분포라는 근본적으로 다른 두 조건을 좌우로 병치해야 "왜 실패하는가"가 직관적으로 전달됨

### 슬라이드 10: 2단계 학습 — 그룹 상대 정책 최적화
- **핵심 메시지**: 같은 상황에서 여러 후보를 생성해 상대 순위로 채점하고, 우수한 쪽의 확률을 높이는 과정을 반복해 가치망 없이 정책을 개선한다
- **주요 개념**: ["절차1: 후보 행동 다수 생성", "절차2: 안전·효율 기준 채점", "절차3: 후보 간 상대 순위 판정", "절차4: 우수 후보 확률 상향", "가치망 불필요 → 보상 해킹 위험 감소"]
- **콘텐츠 분류**: render_text(4단계 절차 라벨) + scene_context(후보 다발이 채점·순위화를 거쳐 한 방향으로 수렴하는 순환 다이어그램)
- **권장 레이아웃**: Cycle
- **레이아웃 근거**: 4단계가 반복 수행되는 최적화 루프이므로 순환 구조 레이아웃이 절차의 반복성을 가장 잘 드러냄

### 슬라이드 11: 대비② 열린 고리 대 닫힌 고리
- **핵심 메시지**: 같은 알고리즘이라도 단일 스텝만 채점하는 열린 고리와, 실제로 끝까지 주행시켜 궤적 전체를 채점하는 닫힌 고리는 분포 이탈 해소 여부에서 갈린다
- **주요 개념**: ["열린 고리: 같은 관측에서 후보 32개 단일스텝 채점", "닫힌 고리: 자기 정책으로 250스텝 롤아웃 후 궤적 채점(시나리오당 12개)", "열린 고리 한계: 분포 이탈 잔존", "닫힌 고리 장점: 학습-배포 조건 일치 / 비용: 계산량 대폭 증가", "비유: 문제집 한 문항 대 실제 도로 한 구간 완주"]
- **콘텐츠 분류**: render_text(핵심 수치: 후보32/롤아웃12/250스텝) + scene_context(정지된 한 장면 채점 대 움직이는 궤적 전체 채점의 대비 장면)
- **권장 레이아웃**: Contrast
- **레이아웃 근거**: 이번 발표의 핵심 대비축. 두 학습 방식의 절차·비용·효과 차이를 좌우 병치로 가장 선명하게 전달할 수 있음

### 슬라이드 12: 보상·보수성 설계 — 전문가 시스템이 심판
- **핵심 메시지**: 사람이 아닌 규칙 엔진이 다섯 기준으로 자동 채점하고, 세 가지 장치로 오프라인 학습의 이탈을 억제한다
- **주요 개념**: ["안전여유(800m 미달분 감점, 가중 3.5)", "항로이탈(300m 기준, 포화함수, 가중 1.15)", "규칙준수(우현회피 가산, 가중 0.45)", "충돌(60m 이내 대폭 감점, 가중 5.0)", "도착(200m 진입 가산, 가중 2.0)", "보수성 장치: 앵커항(가중 4.0)/탐색폭 상한/상대순위 어드밴티지"]
- **콘텐츠 분류**: render_text(5개 보상 항목 + 가중치 수치, 3개 보수성 장치명)
- **권장 레이아웃**: Bento Grid
- **레이아웃 근거**: 보상 5요소와 보수성 3장치라는 서로 다른 성격의 모듈들을 한 장에 압축 요약하기에 적합

### 슬라이드 13: 모델 구조 — 백본 비교와 주변선박 인코더
- **핵심 메시지**: 파라미터 수를 거의 동일하게 맞춘 두 시계열 백본을 비교하고, 가변 개수 타선 집합은 어텐션으로 고정 크기 벡터로 압축한다
- **주요 개념**: ["아이트랜스포머(변수축 어텐션, 80,041개 파라미터)", "LSTM 대조군(80,147개, 차이 0.1%)", "입출력·타선 인코더 완전 동일 고정", "학습된 질의 벡터로 타선 집합 요약", "타선 0척=영벡터"]
- **콘텐츠 분류**: render_text(파라미터 수치, 백본명) + scene_context(두 백본 개요 옆에 타선 집합이 하나의 벡터로 압축되는 처리 흐름)
- **권장 레이아웃**: Section-Flow
- **레이아웃 근거**: "백본 비교 개요"와 "인코더 처리 흐름"이라는 두 성격의 정보를 한 슬라이드의 개요+흐름 구조로 결합하는 데 적합

### 슬라이드 14: 대비③ 명령 언어 — 경유점 대 곡률
