# 사실 자료

## 1. 이 정책이 푸는 문제

중앙의 고가치 **모선** 1척에, 가장자리에서 **적 USV M=10척**이 여러 방위로 동시에 돌진한다.
**아군 방어정 P=3척**이 막는다.

- 아군 **6.0 m/s** < 적 **9.0 m/s** → **추격으로 못 따라잡는다**
- 대신 적의 접근 회랑을 **미리 그물벽으로 가로막는다** (물리적 포획)
- 배당 그물 **1개**, 그물벽 최대 길이 **450 m**

**정책이 결정하는 것**: "이 배는 바다 위 **어느 두 점**을 잇는 그물벽을 놓을 것인가"
**정책이 결정하지 않는 것**: 어느 적을 맡을지(= 상위 LLM 지휘관), 저수준 조타(= PD 추종)

성능 지표: `Capture Rate = N_cap / (N_cap + N_brc)` (포획 / (포획 + 돌파))

## 2. 왜 좌표 회귀가 아니라 "점수맵 위 픽셀 지목"인가 ★핵심 논지

| | 연속 좌표 회귀 | **점수맵 픽셀 선택 (채택)** |
|---|---|---|
| 행동공간 | 무제한 실수 2P개 | **격자 2500칸으로 규제** |
| 배정 위반 | 사후 클리핑 필요 | **마스크로 원천 차단** (로짓 `-inf`) |
| 결정 안정성 | 스텝마다 미세 진동 | **경유점이 격자에 고정** → 기동 안정 |
| 적 수 변화 | 입력 차원이 변함 | **입력 형태 불변** |
| 적 입력 순서 | 결과가 바뀜 | **순열 불변** |
| 해석 | 숫자 2개만 나옴 | **점수맵 자체가 판단 근거 시각화** |

> 회귀의 실패는 조용하다 — 배정 밖 좌표를 뱉어도 에러가 안 난다.
> 마스킹은 그 실패를 **표현 불가능하게** 만든다.

## 3. 관측 — 목록이 아니라 다채널 격자 지도

모선을 중앙에 둔 **50 × 50 격자**, 픽셀 **252 m**, 반폭(extent) **6300 m**, 맵 한 변 **12600 m**.
**총 15채널** = 전역 9 + 배별 3 + 좌표 3.

### 3.1 전역 채널 9 (`gmap` `[N,9,50,50]`) — 배와 무관, 월드당 1장

| # | 이름 | 만드는 법 | 정규화 |
|---|---|---|---|
| 0 | `enemy_presence` | 픽셀별 살아있는 적 수 합산 | `/ 10` |
| 1 | `enemy_vx` | 픽셀 내 적 헤딩벡터 x(=sin) 합 | 그 픽셀 적 수로 평균 |
| 2 | `enemy_vy` | 헤딩벡터 y(=cos) 합 | 〃 |
| 3 | `enemy_threat` | 모선 도달 임박도, 픽셀당 **max** | `1 − clip(d/18000)` |
| 4 | `ally_presence` | 픽셀별 살아있는 아군 수 | `/ 3` |
| 5 | `net_installed` | 물리격자 200²의 설치 그물 → 50²로 **4×4 블록 max** | 0/1 |
| 6 | `origin` | 모선 disk (`r ≤ 260 m`) 정적 마스크 | 0/1 |
| 7 | `annulus` | 요격 환형 (`400 ≤ r ≤ 4500 m`) 정적 마스크 | 0/1 |
| 8 | `land` | 육지 마스크 (OSM 벡터 기반) | 0/1 |

### 3.2 배별 채널 3 (`smap` `[N,P,3,50,50]`)

| # | 이름 | 만드는 법 |
|---|---|---|
| 0 | `self_marker` | 자기 위치 **1픽셀** 스탬프 (`cnn_marker_r=0`) |
| 1 | `self_intercept` | **배정된 요격점** 1픽셀 스탬프 (미배정이면 전부 0) |
| 2 | `self_valid` | 유효 마스크 float 캐스팅 (§5) |

### 3.3 자기상태 스칼라 `own` `[N,P,8]` — 래스터로 그리기 낭비인 값

```
own = [ (x-6300)/6300,  (y-6300)/6300,      # 0,1 자기 위치
        sin(hdg), cos(hdg),                  # 2,3 헤딩 (0°=North, 시계방향 +)
        a_nets / nets_per_ship,              # 4 남은 그물
        float(doing_net),                    # 5 지금 그물 도색 중인가
        (Ix-6300)/6300, (Iy-6300)/6300 ]     # 6,7 배정 요격점 — 미배정이면 0
```

### 3.4 CoordConv 좌표 3채널 — 합성곱의 위치 맹점 보정

`(x−cx)/6300`, `(y−cy)/6300`, `clip(r/6300, 0, 1)`.
합성곱만으로는 물체가 지도 **어디에** 있는지가 흐려진다 → 각 칸의 좌표를 채널로 함께 넣어
**절대 위치를 보존**한다. (Liu et al., 2018, CoordConv)
config에서 완전히 파생되므로 체크포인트에 저장하지 않는다(`persistent=False`).

### 3.5 ★ 정규화가 전부 고정 상수 나눗셈이다

RunningMeanStd / VecNormalize / BatchNorm 같은 **배치 통계 기반 정규화가 하나도 없다.**
모델 내부의 GroupNorm · `/√d` 스코어 스케일 · GAP→FiLM 도 전부 배치 무관.

> **결과: 배치 1 실시간 추론이 학습과 완전히 동일하다. 워밍업 불필요.**
> 실선 배치에서 이게 크다 — 통계 정합을 맞출 일이 없다.

## 4. 신경망 구조 — UNetLite + 질의-특징 내적

**파라미터 244,389개.** (참고: 1 MB 미만 체크포인트)

### 4.1 백본 — 입력 해상도를 유지하는 U-Net

```
 입력 [15, 50, 50]
   │
 stem   (conv×2, w=32)                 [32,50,50] ──────────skip──────┐
   │                                                                  │
 enc1   (stride 2 → conv)              [32,25,25] ────skip───┐        │
   │                                                          │        │
 enc2   (stride 2 → conv, 2w)          [64,13,13]            │        │
   │                                                          │        │
 bottle (conv×2)                       [64,13,13]            │        │
   │                                                          │        │
   ├─ GAP → Linear → (γ, β) ── FiLM ──▶ b·(1+γ) + β          │        │
   │        전역 문맥(전체 전황)을 디코더에 주입               │        │
   │                                                          │        │
 upsample(nearest) + concat ◀──────────────────────────────────┘        │
 dec2   (conv×2)                       [32,25,25]                      │
   │                                                                    │
 upsample(nearest) + concat ◀────────────────────────────────────────────┘
 dec1   (conv×2)                       [32,50,50]
   │
 head   (1×1 conv)                     [d=32, 50, 50]   ← 셀 특징맵
```

- 기본 블록 `_cbr` = `Conv3×3(bias=False)` → `GroupNorm(min(8,C))` → `SiLU`
- 업샘플은 `F.interpolate(size=skip.shape)` → **홀수 크기에서도 안전**하게 복원
- **점수맵 해상도 = 입력 해상도** (U-Net을 쓰는 이유. 50×50 그대로 나온다)
- **FiLM**: bottleneck의 전역 평균(GAP)으로 γ·β를 만들어 디코더 특징을 변조
  → 국소 합성곱이 놓치는 "전체 전황"을 주입

### 4.2 점수맵 = 자기상태 질의 × 셀 특징 내적

```
 own [8] ──▶ MLP(8→128→32) ──▶ q [d=32]
                                  │
 셀 특징 feat [d,50,50] ──────────┼──▶ score = einsum(q_proj(q), feat) / √d
                                       └──▶ [50, 50] 점수맵
```

- 배마다 `own`이 다르므로 **같은 특징맵에서 배별로 다른 점수맵**이 나온다
  (파라미터 공유 = 척수가 늘어도 모델이 안 커진다)
- `/√d` 스케일링은 어텐션과 같은 이유 — 내적 분산 폭주 억제
- `feat`는 `gmap`을 P축으로 expand해 `[N*P, 15, 50, 50]`로 한 번에 통과 → **CNN forward는 결정당 1회뿐**

## 5. 유효 마스크 `valid` — 여기가 진짜 핵심 ★

`valid`는 "그릴 수 있는 영역"이 아니라 **정책의 신뢰영역(trust region)**이다.
로짓을 `-inf`로 막아 **학습 내내 모델이 그 밖을 본 적이 없다.** 대충 만들면 모델이 조용히 무너진다.

### 5.1 구성

```
valid = annulus ∩ ¬land ∩ (요격점 반경게이트 r ≤ 3000 m)
                         ∩ (방위게이트 |Δbearing| ≤ 60°)
```

- **방위게이트의 중심선 = `모선 → 배정 요격점` 축.** 즉 "배정된 클러스터로 뻗는 코리도".
- 실측 유효 픽셀 수(16월드×3시드×12결정): **min 150 / median 241 / max 319** (2500칸 중)

### 5.2 폴백 사다리 — 순서가 의미를 좌우한다

```
 후보 < 150 (cnn_min_valid)  →  soft: 반경게이트만 푼다   ← 방위(코리도)는 절대 안 버린다
 후보 < 2   (cnn_nets)       →  hard: 그제서야 방위 포기 → annulus ∩ ¬land → 맵 전체
                                     (단 육지는 끝까지 제외)
```

min이 정확히 150으로 관측된다는 것은 soft 폴백 하한이 **실제로 작동한다**는 증거다.

### 5.3 그래서 배정(assignment)이 선행 조건이다

`self_intercept` 채널 · `own[6:8]` · 방위게이트가 **전부 상위 배정에 의존**한다.

```
 LLM 지휘관 배정 확정
      ↓
 배별 요격점 I 고정
      ↓
 I 중심 코리도 = valid 마스크
      ↓
 정책은 이 안에서만 픽셀을 고를 수 있다   ← 배정 위반이 구조적으로 불가능
```

> **배정이 바뀌면 후보 영역 자체가 바뀐다.** 마스크가 곧 통제 수단이다.
> 위험한 건 모델이 아니라 **마스크와 배정**이다 — 이 둘이 틀리면 모델은
> **에러 없이 조용히** 엉뚱한 곳을 찍는다.

## 6. 행동 — 픽셀 2개를 자기회귀로 고른다

`K = cnn_nets = 2`. 두 점을 잇는 선분이 그물벽이 된다.

```
 q0 = q
 ── k=0 ────────────────────────────────────────────
   logits = score(q, feat).masked_fill(~valid, -inf)
   pick0  = argmax(logits)                      ← greedy(운용) / sample(학습)
   f0     = feat[:, :, pick0]                   ← 고른 칸의 특징
   offset0= off_mu([q0, f0])                    ← 서브픽셀 ±1 → ±126 m
   valid  = exclude(valid, pick0)               ← ↓ 두 규칙 적용
   q      = q + f0                              ★ 되먹임: 다음 선택이 앞 선택을 안다
 ── k=1 ────────────────────────────────────────────
   pick1  = argmax(score(q, feat) masked)
```

### 6.1 `exclude` 두 규칙 — "너무 가까움"과 "너무 멂"을 동시에 막는다

| 규칙 | 값 | 이유 |
|---|---|---|
| `cnn_dup_r` | 반경 **200 m** 안쪽 제거 | 두 점이 붙으면 그물벽이 안 선다 |
| `reach` 상한 | **675 m** 바깥 제거 | `net_max_len 450 m × slack 1.5`.<br>더 멀면 벽이 목표에 **닿지 못한다** |

reach 상한을 걸어 후보가 **전부** 막히면(코리도가 극단적으로 좁을 때) 원복한다 — 크래시보다 낫다.

### 6.2 두 점이 서로를 알고 뽑힌다

`q ← q + f0`가 이 설계의 요점이다. 독립적으로 두 점을 뽑으면 벽의 **방향**이 우연에 맡겨진다.
첫 점의 특징을 질의에 더해 두 번째 선택을 조건화하면, 두 점이 **하나의 벽으로서** 결정된다.

### 6.3 서브픽셀 — 격자보다 정밀한 좌표

`off_mu = MLP([2d → d → 2])`가 `[q0, fk]`에서 `±1` 오프셋을 낸다 → 실좌표 **±126 m**.
운용은 결정적 μ, 학습만 `Normal(μ, σ)` 샘플(초기 `log_std=-1.2`, σ≈0.30).
출력층 가중치·편향을 **0으로 초기화** → 학습 초기에는 정확히 픽셀 중심에서 시작한다.

### 6.4 크래시 가드

한 행의 픽셀이 전부 무효면 `Categorical(all -inf)`가 터진다
→ `_fallback`이 그 행만 **전부 유효로** 되돌린다.

## 7. 출력 디코딩 — 픽셀에서 위경도 WP까지

### 7.1 픽셀 → 미터 → 위경도 (전부 고정 affine, 학습 요소 없음)

```
 ix, iy = flat // 50, flat % 50
 x = (ix + 0.5) * 252.0 + dx * 126.0        ← dx, dy ∈ [-1, 1] 서브픽셀
 y = (iy + 0.5) * 252.0 + dy * 126.0
 lat = LAT0 + (y - 6300) / 111320.0
 lon = LON0 + (x - 6300) / (111320.0 * cos(LAT0))
```

- 좌표 3층: `WGS84(lat,lon)` ↔ `world(m)` ↔ `픽셀(ix,iy)`
- `MPD_LON`은 **앵커 위도로 한 번만** 계산해 고정 (배 위도마다 다시 계산하면 왕복이 어긋난다)
- 학습 앵커 (34.625°N, 128.52°E) — 통영 매물도 서측
- ⚠ **축 순서 `[ix, iy] = [x, y]`.** numpy 이미지 관례가 아니다. 그림 그릴 때만 전치.

### 7.2 두 점 → 실제 경로 (여기서 규칙이 하나 더 붙는다)

```
 두 점을 배에서 가까운 순으로 정렬
   route[0] = 가까운 점  →  이동 WP        (그물 안 침)
   route[1] = 먼 점      →  그물벽 끝점
   net_mask[1] = True    →  route[0]→route[1] 구간이 그물벽
   route[2:] = 마지막 점 반복 (정지)
```

### 7.3 ★ 정지 규칙 — 빠뜨리면 배가 엉뚱한 데로 간다

```python
done = (a_nets <= 0) | (assign < 0)     # 그물 소진 또는 미배정
route[done] = 현재 위치
net_mask[done] = 0
```

**이유**: 그물이 없거나 미배정인 배는 **행동이 세계를 바꾸지 못한다.**
그런 배는 학습 신호가 0이라 점수맵이 **거의 균등분포**로 남는다
(실측 top1 확률 = 0.012, 균등 = 1/170). 이 균등분포 출력이 그대로 항해 명령이 되는 것을 막아야 한다.

### 7.4 실행 로그 예시 (`enemy=wave, seed=3`)

```
배2: assign=0 nets=1 pos=[6655.4 6724.5]
     raw pts   = [[6669.5, 6665.7], [6170.6, 6925.5]]
     net_mask  = [0,1,0,0,0,0]
     WP0 -> lat 34.628285  lon 128.524034
     WP1 -> lat 34.630619  lon 128.518588
     그물벽 길이 = 562.4 m

배0: assign=-1 nets=1  → route 전체가 현재 위치로 덮임, net_mask 전부 0 (정지)
```

## 8. 학습 — GRPO의 다중 에이전트 변형

```
 한 결정 시점에서
   ├─ 후보 행동 G개 샘플링   (1개는 휴리스틱 행동으로 채움 = 출발점 확보)
   ├─ 각 후보를 시뮬레이터로 일정 구간 진행 → 팀 보상
   └─ 후보끼리의 상대 비교로 이득 산정   ⇒ 가치망(critic) 불필요
```

**개별 기여 분리 (counterfactual credit)**
팀 보상을 모든 배가 그대로 나눠 가지면 개별 기여가 가려진다
→ **한 척의 행동만 바꾸고 나머지는 고정**해 평가, 그 차이를 그 배의 몫으로 돌린다.

**보상**
- 지배 항: **포획(+) · 돌파(−) · 아군의 그물 접촉(−)**
- 위협 근접도에 대한 **퍼텐셜 항** → 최적 정책을 보존하는 형태 (Ng et al., 1999, potential-based shaping)

**초기 학습 부팅 (`bc_loss`)**
휴리스틱이 낸 픽셀을 타깃으로 교차엔트로피. 단일 픽셀 라벨은 신호가 너무 희박하므로
**σ 가우시안으로 라벨 스무딩**해 초기 학습이 실제로 붙게 한다.

**근거 문헌**: Shao et al., 2024 (GRPO) / Ng et al., 1999 (shaping) /
Ronneberger et al., 2015 (U-Net) / Liu et al., 2018 (CoordConv)

## 10. 스케일 불변 — 실해역이든 수조든 같은 가중치

관측이 **무차원**이라 학습 가능한 부분에 절대 길이가 들어가지 않는다.
`tests/test_scale.py`가 **k = 1e-3** 축소에서 동치를 검증했다.

### 10.1 모델이 아니라 시계를 스케일한다

```
 ① 길이 S  [sim-m/real-m] = 12600 / (실제 운용 박스 한 변)
 ② 시간 dt [s/step]       = 6.0 / (실제 아군 속도 × S)      ← ①에서 따라 나온다
```

**10 m 수조 · 모형선 0.4 m/s 실제 출력:**
```
 S  = 1260 sim-m/real-m
 dt = 0.0119 s/step   ·   결정주기 = 0.2976 s (25 step)
 실제 1 픽셀        = 0.2 m
 실제 그물 최대길이 = 0.357 m
 실제 요격 환형     = 0.318 ~ 3.571 m
```

### 10.2 추론이 그 예산 안에 드는가 — 실측 (CPU 4스레드, N=1·P=3·50²)

```
 관측 1.20 ms  +  추론 4.71 ms  +  디코딩 0.15 ms
 = 중앙값 6.13 ms   (p95 8.71 ms)
 예산 297.6 ms 대비 34배 여유 → GPU 불필요
```

### 10.3 ★ 스케일해도 안 따라오는 세 가지 — 정직해야 하는 지점

| 항목 | 문제 | 10 m 수조 예 |
|---|---|---|
| **선회반경** | sim은 `6/0.1396 = 43 sim-m` 고정 | 실제 **3.4 cm**를 뜻함. 모형선이 0.5 m면 **15배 굼뜸** → WP 추종 궤적이 학습과 달라짐 |
| **선체 길이 비** | `ship_len = 230 sim-m` | 수조에서 **0.18 m**. 모형선이 0.4 m면 2.19배 → 충돌·포획 판정 어긋남 |
| **속도비 `ve/va = 1.5`** | 위협이 방어보다 1.5배 빠르다는 전제 | 깨지면 요격 가능 영역 자체가 달라짐 |

`SimScale.report(...)`가 이 셋을 대조해 경고를 찍는다:
```
[scale] ⚠ 선회반경 0.5 m > 허용 0.0341 m — WP 추종이 학습과 달라진다
[scale] ⚠ 선체길이 비 2.19× — 충돌·포획 판정 스케일이 어긋난다
```

## 16. 용어 · 표기

| 기호 | 뜻 |
|---|---|
| `P` / `M` | 아군 방어정 수(3) / 적 슬롯 수(10, 고정) |
| `K` | 결정당 선택 픽셀 수(2) |
| `d` / `w` | 셀 특징 차원(32) / U-Net 채널 폭(32) |
| `valid` | 행동 마스크. `-inf` 로짓으로 선택 불가 영역을 만든다 |
| `assign` | 상위 LLM 지휘관이 정한 배 → 적 무리 배정. `-1` = 미배정 |
| 요격점 `I` | 배정된 클러스터에 대해 정해지는 목표점. 마스크 코리도의 중심 |
| `doing_net` | 그물 도색 중 — 이 동안 재계획이 동결된다 |
| `a_nets` | 배별 남은 그물 수 |
| 헤딩 규약 | **0° = 북, 시계방향 +.** GPS/IMU true heading과 동일 |
